# Сортировка в списке или таблице

Используй этот навык, когда нужно изменить порядок строк в динамическом списке, форме выбора или табличной части 1C.

## Главное правило

Сортировку выполняй через стандартное дополнительное меню конкретного списка или
таблицы: `Еще > Настроить список` (обычно, для динамических списков) или `Еще > Сортировать по возрастанию/убыванию` (обычно, для табличных частей).

Не сортируй кликом по заголовку колонки, так это не работает. Вместо этого, пользуйся вспомогательными стандартными меню, которые явно показывает доступные команды сортировки и настройки.

## Нюансы сортировки

Сортировка в динамических списках и табличных частях работает по разному. Как правило, у динамических списков есть меню `Настроить список`. Это меню открывает сложный диалог с настройками, в числе функций которого есть возможность задать сортировку. В отличие от сортировки табличных частей, в динамических списках сортировка может быть настроена по одному или нескольким полям, включая даже те, которые в списке не отображаются, с возможностью указания направления сортировки.

Функциональность сортировки табличных частей как правильно проще. У табличной части есть меню `Сортировать по возрастанию` и `Сортировать по убыванию`. При этом, никакие дополнительные диалоговые окна не открываются и сортировка производится по текущей колонке табличной части. Для установки текущей колонки, можно использовать метод `Фокус`.

После применения сортировки, текущая строка в списке/таблице остаётся, и автоматически не уходит в начало или конец списка.

## Типичные ошибки

- Перед началом сортировки в динамическом списке, обязательно проверь текущие настройки сортировки. Если ты просто добавишь в таблицу сортировки поле, оно может стать следующим по счёту полем для сортировки, и полученный результат может не соответствовать твоим ожиданиям.
- Не считай сортировку примененной без проверки результата.
- Не смешивай сортировку с поиском или фильтрацией. Для поиска и отбора записей используй навык `search-in-list`, а затем при необходимости применяй этот навык для порядка строк.
- Табличные части документов или справочников, как правило, редко требуется сортировать. Более того, часто это и не правильно, потому что может нарушить следование введённых пользователем строк из первичного документа. Если тебе нужно что-то проанализировать в табличной части, возможно лучшим решением будет использование меню `Вывести список`, которое позволяет экспортировать данные табличной части в отдельный текстовый или табличный документ.
